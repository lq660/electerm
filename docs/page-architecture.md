# 云舵工作台页面结构规划

> 2026-07-03 coder(lq): 先固定产品信息架构，再按页面模板改 UI，避免继续在原 electerm 页面上零散叠皮肤造成错位。

## 目标

云舵工作台面向国内运维、开发、实施人员，核心体验不是“设置很多”，而是快速找到服务器、打开会话、传文件、执行命令、维护连接配置。

页面规划要解决四个问题：

- 哪些页面是日常工作页面。
- 哪些页面是资源管理页面。
- 哪些页面是真正的系统设置。
- 不同页面使用哪种固定布局模板。

## 总体导航

一级导航固定在左侧窄栏，表达“去哪里”。顶部 Tab 只表达“当前打开了什么会话”。

```text
左侧一级导航：
- 工作台
- 服务器
- 文件
- 传输
- 命令
- 凭据
- 设置
```

```text
顶部 Tab：
- SSH 会话
- 本地终端
- SFTP 文件页
- RDP/VNC/Web 会话
- 临时编辑器
```

```text
页面分区：
左侧 = 全局导航 / 资源树
顶部 = 当前打开的会话 Tab
中间 = 当前页面主内容
右侧 = 当前上下文辅助信息
```

## 页面职责

### 1. 工作台

定位：用户打开软件后的默认落点。

功能：

- 快速连接输入框。
- 本地终端快捷入口。
- 新建连接入口。
- 最近连接。
- 常用服务器或收藏服务器。
- 传输任务简要状态。
- 快捷命令入口。

不应该放：

- 复杂服务器编辑表单。
- 系统设置项。
- 大量宣传式说明。

布局模板：`Dashboard`

```text
左：服务器资源树或全局资源入口
中：快速连接 + 工作卡片
右：最近连接 / 动态 / 传输简报
```

### 2. 会话页

定位：真正执行工作的页面。

功能：

- SSH/Telnet/Serial/本地终端。
- RDP/VNC/SPICE/Web 远程页面。
- 当前会话搜索、复制、粘贴、重连、断开。
- 会话内快捷命令。
- 可选的 SFTP、监控、日志辅助面板。

不应该放：

- 全局服务器配置。
- 软件设置。

布局模板：`Session`

```text
顶部：会话 Tab
中间：终端或远程画面
底部：当前会话状态栏
右侧可选：会话上下文工具
```

### 3. 文件管理

定位：围绕本地和远程文件的工作页。

功能：

- 本地文件列表。
- 远程 SFTP/FTP 文件列表。
- 双栏传输。
- 上传、下载、重命名、删除、新建目录。
- 传输队列状态。

布局模板：`Split File Manager`

```text
顶部：路径栏和操作按钮
左：本地文件
右：远程文件
底部：传输队列摘要
```

### 4. 服务器资源

定位：维护和选择连接资源。

功能：

- 服务器分组。
- 标签和搜索。
- 最近连接。
- 收藏/常用。
- 导入 SSH Config。
- 新建连接入口。

不应该放：

- 软件级设置。
- 终端外观配置。

布局模板：`Resource Master`

```text
左：全局窄栏
中左：服务器树 / 搜索 / 分组
中右：选中服务器摘要或空状态
```

### 5. 连接详情

定位：服务器资源的详情编辑页，不是系统设置页。

功能：

- 协议类型选择：SSH/SFTP、Telnet、串口、本地终端、VNC、RDP、FTP/SFTP、Web、SPICE。
- 基础信息：标题、分组、主机、端口、用户名。
- 认证方式：密码、私钥/证书、配置文件。
- 高级设置：编码、环境变量、启动目录、代理。
- SSH 隧道。
- 连接跳跃。
- 快捷命令绑定。
- 保存、保存并连接、测试连接。

布局模板：`Detail Form`

```text
顶部：页面标题 + 协议切换
中间：分组表单区
底部：固定操作按钮
```

### 6. 传输任务

定位：所有文件传输的统一队列。

功能：

- 进行中。
- 已完成。
- 失败。
- 暂停、继续、取消、重试。
- 打开本地目录。

布局模板：`Task Queue`

```text
顶部：状态筛选
中间：任务表格
右侧/底部：任务详情
```

### 7. 快捷命令

定位：常用命令和脚本片段管理。

功能：

- 命令列表。
- 分组和标签。
- 命令内容编辑。
- 变量参数。
- 适用连接类型。
- 一键执行或批量执行。

布局模板：`List Detail`

```text
左：命令列表
右：命令详情表单
```

### 8. 凭据管理

定位：敏感信息和认证材料管理。

功能：

- 保存的密码。
- 私钥和证书引用。
- SSH Agent 配置。
- 凭据搜索。
- 安全提示。

布局模板：`Security List Detail`

```text
左：凭据类型 / 列表
右：详情 / 使用范围 / 安全操作
```

### 9. 设置中心

定位：只管理软件自身偏好。

功能：

- 通用设置。
- 终端设置。
- 外观主题。
- 快捷键。
- 同步设置。
- AI 设置。
- 插件/工具面板。
- 更新与关于。

不应该放：

- 新建服务器连接。
- 编辑具体服务器账号密码。
- 当前会话操作。

布局模板：`Settings`

```text
顶部：设置中心标题
左：设置分类
右：设置项表单
```

## 布局模板

### Dashboard

用于：工作台。

要求：

- 信息密度中等。
- 第一屏可完成快速连接。
- 卡片只承载独立功能块，不嵌套卡片。
- 终端预览可以是深色，其他区域保持浅色。

### Session

用于：终端、远程桌面、Web、串口。

要求：

- 内容区优先。
- 工具栏收敛，不抢终端空间。
- 深色只属于终端画布或远程画面，不扩散到应用外框。

### Resource Master

用于：服务器资源。

要求：

- 左侧树可搜索、可折叠。
- 右侧默认显示资源摘要，不直接塞完整表单。
- 新建/编辑进入连接详情页。

### Detail Form

用于：连接详情。

要求：

- 标签列固定宽度。
- 控件列统一宽度。
- 表单分组明确。
- 底部操作按钮固定在表单底部。
- 复合输入框不能出现内部边框错位。

### List Detail

用于：快捷命令、连接模板、工具面板。

要求：

- 左侧是对象列表。
- 右侧是当前对象详情。
- 搜索、创建、删除在列表区完成。
- 保存、测试、执行在详情区完成。

### Settings

用于：设置中心。

要求：

- 设置项只影响软件自身。
- 分类不超过两层。
- 每个设置块有标题和一句解释。
- 不把连接编辑混进设置中心。

## 推荐迁移顺序

1. 固定一级导航和顶部 Tab 语义。
2. 把“新建连接/编辑连接”从设置感页面改成服务器资源的详情页。
3. 收敛设置中心，只保留软件配置。
4. 重做工作台首页，让它只承担日常入口。
5. 统一表单基线：标签宽度、输入宽度、分组标题、底部按钮。
6. 再逐页处理快捷命令、主题、连接模板、工具面板。

## 当前需要避免的做法

- 不再用全局 CSS 大范围覆盖所有 `.ant-input`、`.form-wrap`、`.setting-row`。
- 不再让同一个页面同时承担“工作台、资源管理、设置中心”三个职责。
- 不再在首页内重复做服务器树，服务器树应该是全局资源区。
- 不再把连接编辑页当成系统设置页。
- 不再用临时补丁逐个修控件，应先套对应布局模板。
